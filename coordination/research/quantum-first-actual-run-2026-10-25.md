# QuantDeus — результаты первого реального вычислительного теста (25.10.2026)

**Источники:** локально проанализирована предоставленная автором рабочая рукопись `QuantDeus_Integral_Philosophy_Master.docx`; использован каталог `coordination/growth/ru-lexical-topology-atlas.md`. Полный текст рукописи в репозиторий не публикуется.

**Классификация:** предварительный эксперимент по выбору тем/пилотов, *не* измерение аудитории России и *не* физический QPU.

## Фактически выполненное
- Число задач: 2; в каждой 8 бинарных переменных => классический полный перебор 256 комбинаций, суммарно 512.
- На локальном CPU запущена **эмуляция QAOA** для 8 кубитов, глубина p=2, 2048 смоделированных измерений для каждой задачи, SciPy/Numpy.
- Относительный приоритет темы задавался через частоту тематических подстрок в рукописи (не запросы пользователей!), журналируемые экспертные бонусы и заранее зафиксированные связи между темами.
- Модель: выбрать 3 из 8, максимизируя искусственный рейтинг `sum(topic_score) + sum(pair_synergy) - 5.5*(selected-3)^2`; точный оптимум определён перебором.

## Миссия #626 — российские темы
- Точный модельный оптимум **13.7239**: **интегральная философия + ИИ и агенты + образование/лаборатории**.
- QAOA (локальная эмуляция) нашла оптимальный набор с вероятностью **0.015010**; наиболее вероятный набор симулятора — философия + ИИ и агенты + виртуальные миры. При 2048 виртуальных измерениях.
- Полных данных о поисковых запросах по РФ в этом тесте **нет**; размер потенциальной аудитории **не установлен**.

## Миссия #627 — Земля 2126
- Точный модельный оптимум **15.6212**: **ИИ с человеческим контролем + виртуальные лаборатории + открытое образование**.
- QAOA (локальная эмуляция) вероятность точного оптимума **0.003499**; наиболее вероятный набор не был точным оптимумом.
- Модельные веса не являются научно измеренной зрелостью технологии, сметой или прогнозом 2126 года.

## Cloud qBraid (проверено отдельно)
- GitHub Actions [проверка qBraid](https://github.com/quantdeus/quantdeus.github.io/actions/runs/40134225922) завершена **success**, реальный запрос Cloudflare→qBraid зафиксирован в D1.
- qBraid API вернул `usage_http=200`, `balance_http=200`, 11 симуляторов, 50 оставшихся GPU-схем и 900 обычных бесплатных слотов; `billing_disabled=1`.
- Готовятся две удалённые тестовые схемы, но **пока нет подтверждённых qBraid job ID**; любые результаты местного QAOA нельзя называть облачными.
- Платный QPU доступ и активация платного fallover запрещены.

## Эпистемические ограничения
Количество словоформ и терминов не измеряет численность уникальных людей. Одни и те же люди и запросы встречаются в нескольких платформах. Содержание книжного текста — не российские рыночные данные. QAOA в текущем тесте **не обогнала точный классический перебор**. Цифры — демонстрация воспроизводимого вычисления, не научное открытие или маркетинговое заключение.
