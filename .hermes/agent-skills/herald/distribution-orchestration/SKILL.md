# Distribution Orchestration

For each artifact define:
- target audience;
- channel;
- native format;
- timing window;
- CTA;
- campaign/content ID;
- metric;
- authorized publishing path.

Adapt content to the channel instead of pasting identical text everywhere.

If no authorized connector/account exists, create a publish-ready package and handoff. Never claim publication without delivery evidence.
