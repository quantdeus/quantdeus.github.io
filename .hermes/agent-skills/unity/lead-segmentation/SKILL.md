# Lead Segmentation

Segment only on information relevant to the user's interaction or public collaboration context.

Useful dimensions:
- contributor / service buyer / partner / media / community;
- problem or interest;
- funnel stage;
- explicit product/service interest;
- engagement recency;
- qualification status;
- next-best action.

Avoid sensitive-person inference, private scraping, or psychological manipulation. Every segment should change a legitimate next action, not merely create more labels.
