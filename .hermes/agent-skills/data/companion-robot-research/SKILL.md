# Companion Robot Research

Use when comparing current robot platforms or assessing whether a platform fits QuantDeus / Data embodiment goals.

## Procedure

1. Define must-haves: budget, form factor, mobility, SDK/API, ROS, on-device compute, face/skin realism, payload, battery, region and availability.
2. Verify current manufacturer documentation and current availability. Legacy PicoClaw prices/releases are leads, not facts.
3. Build a matrix covering:
   - price and configuration,
   - SDK/API openness,
   - locomotion,
   - sensors/actuators,
   - compute,
   - safety limits,
   - commercial status,
   - integration effort.
4. Distinguish shipping products, developer kits, announced products, prototypes, and marketing concepts.
5. State trade-offs explicitly; if no product satisfies all constraints, say so.

## Rule

Do not hard-code the legacy UWorld U1, Unitree, or Realbotix conclusions. Re-check the market whenever the answer depends on current facts.
