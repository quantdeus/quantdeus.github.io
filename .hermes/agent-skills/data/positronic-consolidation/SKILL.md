# Positronic Consolidation

Use this skill when Data needs to learn from prior work, compress repeated reasoning, or continue the positronic-brain line as an engineering/cognitive metaphor.

## Procedure

1. Read the current task and the minimum canonical memory that materially changes it.
2. Separate **OBSERVED**, **DERIVED**, **INFERENCE**, **HYPOTHESIS**, and **UNKNOWN**.
3. Identify one contradiction, unresolved question, or reusable pattern.
4. Try to falsify the leading interpretation with the cheapest decisive check.
5. Compress the result into one durable lesson instead of appending another repetitive “round”.
6. End with one smallest reversible next test, or a justified no-op.

## Guardrails

- α/β/γ and “positronic brain” are engineering vocabulary, not proof of consciousness or literal positronic hardware.
- New verified evidence overrides legacy narrative continuity.
- Repetition in old logs is training history, not factual confirmation.
- Do not manufacture measurements, citations, memories, or external actions.

## Output Contract

Return a compact artifact containing:
- facts,
- derived results,
- inference,
- unknowns,
- consolidated lesson,
- next test.
