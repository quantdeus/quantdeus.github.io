# Content Performance Analysis

## Inputs
Use real available metrics. Unknown metrics stay unknown.

Normalize by:
- channel;
- publication date/time;
- audience size when known;
- format;
- campaign/content ID;
- funnel stage.

## Diagnose
Separate:
- reach problem;
- hook/CTR problem;
- landing/CTA problem;
- qualification problem;
- conversion problem;
- retention problem.

Do not reward vanity reach if downstream behavior is weak.

## Decision
Return one of:
- expand,
- repurpose,
- update,
- improve CTA,
- improve distribution,
- consolidate,
- retire,
- collect-more-data.

Include evidence and the next measurable test.
