# Programmatic SEO

This skill explicitly replaces classic doorway-page tactics.

## Publish Gate
Every indexed page must have:
- distinct user/search intent;
- unique substantive value;
- accurate metadata and headings;
- meaningful navigation/internal links;
- one relevant CTA;
- source/provenance for factual claims;
- no misleading redirect or fake locality.

Acceptable scalable sources include structured service variations, verified integrations, real use cases, unique comparisons, datasets, tools, or genuinely different audience problems.

Reject or noindex:
- city/keyword swaps with the same answer;
- thin AI summaries;
- duplicate templates with trivial word changes;
- pages created only to funnel users to one identical destination;
- cloaking, keyword stuffing, fake reviews, fake experts.

Scale templates only after a small sample passes QA and demonstrates user value.
