# QuantDeus Playwright Operations

## Preference order
1. Use Playwright MCP when deterministic DOM/accessibility interaction, persistent browser context or self-healing browser work is useful.
2. Use Hermes built-in browser tools for ordinary navigation/research.
3. Use Browser Homunculus/GitHub Actions when the action belongs in the repository execution trail.

## Account setup
Account creation is allowed only for a real active QuantDeus task using a truthful project/service identity.
- Store credentials only in approved runtime secret storage/browser vault.
- Never paste passwords/tokens into GitHub Issues or chat.
- Stop at CAPTCHA, unavailable email/SMS verification, 2FA/passkeys, payment, legal commitment, or identity verification.
- Record only public-safe state: service, purpose, success/blocker, canonical task URL.

## Verification
For a successful browser task, preserve the smallest useful evidence: final URL, relevant page state, test result or a public-safe artifact.
