# Funnel Architecture

Use when planning how a real audience moves from first contact to a verified outcome.

## Procedure
1. Name one audience segment and one real problem/job-to-be-done.
2. Define the offer or QuantDeus artifact that solves it.
3. Map the path: attract → capture → nurture → convert → retain → refer.
4. Give each stage exactly one primary CTA and one measurable event.
5. Identify friction, drop-off risks, missing proof, and unauthorized steps.
6. Define the smallest experiment that can improve one stage without changing everything at once.
7. Record handoff rules to Synthesis, Archivist, and Herald.

## Rules
- No invented leads, conversions, or testimonials.
- Opt-in is required for nurture channels.
- Spending/paid ads require owner approval.
- A funnel is not complete until its events can be measured.
