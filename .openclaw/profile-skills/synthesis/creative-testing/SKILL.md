# Creative Testing

Create a test matrix with:
- stable audience/offer;
- one variable under test;
- 2–4 meaningfully different variants;
- primary metric;
- expected learning;
- stop/iterate rule.

Good variables: hook, visual concept, proof type, CTA, opening structure, length, format.
Bad test: changing audience, offer, channel, creative, and CTA at the same time.
