# Nurture Automation

## Sequence Pattern
1. welcome / expectation setting;
2. immediate useful value;
3. proof/demo/case;
4. objection or FAQ;
5. relevant next action;
6. optional follow-up/reactivation.

Branch based on legitimate behavior such as joined, clicked, replied, requested quote, contributed, or became inactive.

Rules:
- opt-in/authorized channel only;
- respect unsubscribe/decline;
- frequency caps;
- no fake urgency or manipulative pressure;
- stop sequences after conversion when they no longer make sense.
