# SEO & Content Intelligence

## Workflow
1. Identify real audience questions and search intent.
2. Cluster by problem/topic, not keyword stuffing.
3. Map each intent to an existing or justified new page.
4. Find cannibalization, duplicate pages, orphan pages, stale claims, and missing internal links.
5. Prefer updating/consolidating an existing strong page over creating a weak new one.
6. Define evidence/provenance and a useful CTA.
7. Measure impressions/clicks/conversions when real analytics are available.

SEO serves useful content; it is not a license to mass-produce search-first pages.
