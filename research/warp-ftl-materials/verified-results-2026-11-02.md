# QuantDeus — три материала против варп-метрики: воспроизводимый численный отчёт

**Дата:** 2026-11-02. **CI:** [GitHub Actions 41442900165](https://github.com/quantdeus/quantdeus.github.io/actions/runs/41442900165), `success`, **6/6 unit tests**. **Рабочая ветка:** `research/warp-ftl-three-materials-20261102`; draft PR #658, не слит.

## Метод и границы
- Из Materials Cloud OPTIMADE `2dtopo` получены **реальные атомные записи** для трёх закреплённых структур по UUID. Это 2D кристаллы; формальная объёмная плотность по 3D ячейке **некорректна**, потому вычислена масса на единицу площади по первому и второму вектору решётки.
- Для каждой структуры получены число атомных позиций, состав, площадь ячейки и поверхностная плотность по стандартным атомным массам (простейшая модель идеального бесдефектного монослоя).
- **Варп-метрика не генерируется атомами**: взят заранее заданный пузырь Алькубьерре с `R=10 m`, шириной стенки `δ=1 m`, `v/c ∈ {0.5,1,2}` и `f(r)=[1−tanh((r−R)/δ)]/2`.
- Энергия `E = -(c⁴/G)(v/c)²/12 ∫r²(df/dr)² dr` вычислена численно методом Симпсона (8000 разбиений) и относится к *формально заданной* метрике. Это **не моделирование производства отрицательной энергии конкретными материалами**.
- Для интуитивного сравнения вычислена положительная энергия покоя `E_rest=M_shell c²` у гипотетической однослойной сферической оболочки площадью `4πR²`, хотя её реальная гибкость, стабильность и возможность изготовления не анализируются.
- Отношение модулей энергий **не означает**, что положительную энергию материи можно обратить в отрицательную энергию. Метрика при `v>c` сталкивается также с проблемами горизонтов, причинности и управления.
- **Не выполнялись** новые qBraid задачи, реальные квантовые расчёты, оптимизация материалов, физические эксперименты или производство.

**Что обнаружено:** у заданной FTL-метрики колоссальная формальная потребность в отрицательной энергии; ни один из этих материалов не обеспечивает её и не демонстрирует FTL.

## Следующая научная развилка
1. По опубликованным результатам найти **измеренные** оптические/электромагнитные параметры этих структур (ε(ω), μ(ω), дисперсия, частоты, температура), сначала оценить существование данных.
2. Только после этого делать отдельную материало-зависимую модель метаповерхности — она не будет автоматически FTL.
3. Публиковать утверждения о работоспособном варп-устройстве только после отдельного доказательства механизма, способного породить нужный тензор энергии-импульса, и независимой проверки.
