# QuantDeus Warp Lab v0.1 — проверка FTL-гипотез

**Статус:** математическая диагностическая модель, а не готовый двигатель.
**Цель:** воспроизводимо проверить энергетический барьер исходной метрики
Алькубьерре и отделить инженерную QA-проверку кода от физической реализуемости.

## Математическая постановка

В геометризованных единицах G=c=1 исходная метрика:

    ds² = -dt² + (dx − v_s f(r_s)dt)² + dy² + dz²

Здесь v_s — координатный параметр скорости центра пузыря (значение 2 означает
формальный сверхсветовой случай, а НЕ достигнутую скорость аппарата).
Для постоянной скорости центр x_s(t)=v_s t, а
r_s = sqrt((x-x_s(t))² + y² + z²).
В расчётном моменте t=0 используется x_s=0.

Функция формы:

    f(r) = [tanh(σ(r+R)) − tanh(σ(r−R))] / [2 tanh(σ R)]

Энергетическая плотность, измеряемая эйлеровым наблюдателем
(единицы G=c=1):

    ρ_E = −v_s²/(32π) * [(∂_y f)² + (∂_z f)²].

Она отрицательна на части стенки пузыря при ненулевой скорости: слабое
энергетическое условие (WEC) нарушается для **этой** метрики. Наш численный
тест подтверждает этот конкретный результат, но не проверяет произвольные
другие варп-геометрии.

## Критерии QA

- **Программный QA:** формулы, численная производная, масштабирование по
  квадрату скорости, центральные условия, воспроизводимость.
- **Научный QA:** 10 независимых проверок из существующего механизма
  QuantDeus warp-evidence-gate-checker.js.
- **Геометрия = PASS:** математическое определение исходной метрики задокументировано.
- **Остальные 9 = UNKNOWN:** подтверждений экспериментальной FTL-реализации нет.
  В частности, отрицательная плотность энергии — известный барьер,
  а не признак работоспособности двигателя.
- Ни один зелёный GitHub Actions job не означает доказательство FTL.
