# Skyrim Mobile · трёхэтапный план · инженерный контракт
**Исходный документ:** `Skyrim_Android_WebGL_3_stages.md` · пользовательская версия 1.0 · 10.10.2026

## Этап 1 — фундамент (Prototype 0.1)
TypeScript + Vite + Babylon.js / WebGL 2, PBR-сцена, сенсорные органы управления, базовый RPG runtime, локальное сохранение. Разделение renderer / logic / assets. Первый Gate — реальный Android 30-минутный тест, три профиля качества, загрузка GLB/KTX2 по проверенному manifest.

## Этап 2 — RPG вертикальный срез (0.5)
Ячейки 128–256 м, состояния unloaded/requested/decoded/uploaded/active/dormant/disposed, ландшафт и LOD, NPC (idle/patrol/work/talk/flee/fight/sleep), диалоги, бои, инвентарь и единый сюжетный квест: старейшина → караван → руины → артефакт → награда. До расширения карты нужны воспроизводимые сохранения и мобильный FPS.

## Этап 3 — Android Release Candidate (1.0)
Нативная Kotlin/WebView оболочка с локальным HTTPS asset layer, независимые immutable пакеты, SHA-256, atomically staged updates, сохранение рабочих пакетов и rollback. APK лёгкий; **всё, включая пакеты, укладывается в 500 000 000 байт**. Нужны подписанный APK, offline-first, измерение 45–60 минут, аудиторский перечень лицензий.

## Принятые ограничения
- Производить **оригинальную** RPG, а не распространять защищённые файлы Bethesda.
- Код и мир в этой ветке не влияют на production QuantDeus и ветку `main`.
- Сборки и тесты — измеряемые артефакты, не отчёты «всё готово».
- Claude review через Composio только при доступном подлинно подключённом исполнителе.
- Публичный релиз блокируется до прохождения Gate 3.
