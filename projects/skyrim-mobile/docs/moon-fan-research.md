## 🌕 Лунная программа фаната (исследовательская сцена)
Отдельная страница `moon.html` — интерактивный игровой эксперимент с оригинальным персонажем-фанатом, вдохновлённым механиками спутников Bethesda. Не является портом оригинального Skyrim и не содержит его моделей, кода, голосов или иных ресурсов.

**Игра:** WASD / сенсорный стик — движение, мышь/касание игрового поля — поворот, пробел/🦘 — лунный прыжок, E/💬 — следовать или ждать, F/🚀 — запуск фаната по баллистической траектории, R/🛸 — спасение. Состояние сохраняется отдельно от основной долины.

**Движок:** тот же Babylon.js, что уже установлен в прототипе; модель поведения отделена в `src/moon-state.mjs`, тестируется `tests/moon.test.mjs`. Лунная гравитация 1,62 м/с²; NPC реализован как конечный автомат `follow / wait / flight`. Это стилизация, а не точная симуляция коллизий и не запуск оригинального Creation Engine.

**Сборка:** `npm install && npm test && npm run build`. В `dist/` должны появиться обе страницы: `index.html` и `moon.html`.

**Технические источники:** Skyrim Creation Kit — пакеты Follow/Travel/Flee (https://ck.uesp.net/wiki/Category:Procedures); Oblivion Adoring Fan и Starfield companion — исследование поведения персонажей (https://help.bethesda.net/app/answers/detail/a_id/60877/). Никаких ресурсов Bethesda в GitHub.

**Не проверено:** реальное Android-устройство, нагрев/FPS, APK и перенос игрового мира Skyrim.
