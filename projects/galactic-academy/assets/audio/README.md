# Audio assets (private, optional)
Place original and properly licensed Suno music in `suno_main.ogg` or `suno_main.mp3`.
Place your *own* locally stored V17-like personal recording in `v17_local.ogg` or `v17_local.mp3`.
The main soundtrack is foreground. Personal audio is independent, quiet, OFF until the player opts in. No sound files are committed.
Restart the Godot editor for import after copying audio.

This feature is for user-controlled listening/relaxation and is not validated medical treatment.
