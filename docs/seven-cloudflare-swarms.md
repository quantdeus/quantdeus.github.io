# Единая координация Seven of Nine

## Что реально связано

- **Главный контур:** `quantdeus/quantdeus.github.io`. Seven of Nine формирует приоритеты на основе GitHub Issues/PR и измеренных снимков; у неё нет права обходить проверку качества или решение человека.
- **Cloudflare Galactic Swarm:** существующий Worker `quantdeus-galactic-metaverse`, включая виртуальные профили роя. Профили не означают 10 000 одновременно работающих ИИ.
- **Warp Research:** отдельный Worker и научные отчёты в D1.
- **Warp Scheduler:** Worker с почасовым запуском и лимитом ИИ-вызовов (конфигурацию и фактические вызовы проверять раздельно).

## Мост

`https://quantdeus-seven-bridge.quantdeus-galactic-swarm.workers.dev/api/status`

Отдельный `quantdeus-seven-bridge` читает общую D1 и проверяет связь с тремя Cloudflare Workers через service bindings. Он не принимает команды записи. Скрипт `scripts/cloudflare-swarm-bridge.js` проверяет схему ответа, фильтрует поля, ограничивает числа и с тайм-аутом передаёт проверенный снимок `scripts/seven-of-nine.js`. При недоступности Cloudflare координация GitHub продолжается, а статус помечается «недоступен».

**Иерархия:** CEO → Seven of Nine → Swarm Secretary → специализированные рои; независимые QA, научное рецензирование и Human Override остаются обязательными.

## Что этот этап не делает

Публичный мост не принимает задания, не выполняет GitHub Actions, не назначает платные работы, не изменяет WordPress, не торгует и не выдаёт права администратора. Автоматическое распределение команд из GitHub в Cloudflare — отдельная стадия с доказанной подлинностью команд и журнальной записью; отсутствие такого канала нельзя выдавать за полное автономное управление.

## Проверка

`node --test tests/cloudflare-swarm-bridge.test.js`

Проверка существования всех связей выполняется в `.github/workflows/seven-cloudflare-bridge-tests.yml`. Успешная проверка JSON-схемы не означает, что агенты действительно сделали расчёты.
