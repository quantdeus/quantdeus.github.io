# OpenClaw Office runtime

The named persistent Vercel Sandbox `quantdeus-openclaw-office` is borrowed by requests. Each request has isolated config, prompt and checkout paths; cleanup never stops or snapshots the shared VM. The session timeout owns lifecycle. Queue contention returns HTTP 503. An explicitly configured `OPENCLAW_GATEWAY_MODEL` uses existing Vercel OIDC or an existing key and still passes the real capability probe. No billing or public Control UI port is created by this change.

GUI evidence on 2026-10-01: the Office repeatedly stopped/resumed, had no open ports, and Pollinations generation returned 402 followed by OpenClaw 502. Vercel AI Gateway showed $0.00 credit and free-credit activation required card verification. Native OpenClaw Control UI is therefore not yet running; its port and authenticated pairing must be added only after model access is available.
