# OpenClaw Office runtime

The named persistent Vercel Sandbox `quantdeus-openclaw-office` is borrowed by interactive/trusted requests. Each request has isolated config, prompt and checkout paths; cleanup never stops or snapshots the shared VM. Queue contention returns HTTP 503. Recurring scheduling is intentionally separated into `quantdeus-openclaw-scheduler`: a 1-vCPU persistent Sandbox whose local-only token-auth OpenClaw Gateway owns automations in SQLite. A watchdog wake creates a 20-minute session window; while the same Gateway session is healthy, each 15-minute heartbeat extends it by another 15 minutes. When the plan's continuous-session ceiling rejects a further extension, the runtime drains bounded command jobs for 20 seconds, snapshots/stops the persistent Sandbox, resumes it into a fresh 20-minute session, and restarts the Gateway against the same SQLite state. `skipMissedJobs: false` provides catch-up across the brief rotation. Workflow dispatch itself is network-bounded to 15 seconds, so rotation cannot strand a scheduler command indefinitely. The scheduler dispatches only allowlisted `workflow_dispatch` workers without an LLM turn. No public Control UI port is exposed.

GUI evidence on 2026-10-01: the Office repeatedly stopped/resumed, had no open ports, and Pollinations generation returned 402 followed by OpenClaw 502. Vercel AI Gateway showed $0.00 credit and free-credit activation required card verification. Native OpenClaw Control UI remains unexposed. The scheduler Gateway is local-only and authenticated; adding any public UI or pairing surface remains a separate owner-gated change.
