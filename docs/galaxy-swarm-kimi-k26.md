# Подключение Kimi K2.6 через Cloudflare Workers AI

**Статус:** код подготовлен; production-маршрут не включён. Проверка API от 2026-10-19 обнаружила, что текущий Cloudflare-аккаунт работает на Workers Free, где Kimi K2.6 недоступна.

## Настройка

В серверных переменных окружения Vercel задать:

- `QD_CLOUDFLARE_AI_ENABLED=true` — включить маршрут после получения платного доступа.
- `CLOUDFLARE_ACCOUNT_ID` — ID аккаунта Cloudflare.
- `CLOUDFLARE_API_TOKEN` — токен API с минимальными правами для Workers AI; хранить только как secret.
- `QD_CLOUDFLARE_AI_MODEL=@cf/moonshotai/kimi-k2.6` — необязательное переопределение модели.
- `CLOUDFLARE_AI_GATEWAY_ID` — необязательный ID AI Gateway.
- `QD_CLOUDFLARE_AI_TIMEOUT_MS=40000` — необязательный таймаут; код ограничивает его 45 секундами, чтобы оставить запас в лимите Vercel.

Запросы отправляются на OpenAI-совместимый Cloudflare endpoint `/ai/v1/chat/completions`. Если провайдер недоступен, код использует существующий Vercel AI Gateway как резервный маршрут. Секреты и текст запросов не записываются в диагностический лог.

## Ограничение доступа и стоимости

Cloudflare вернул HTTP 403 / код 5035 на тестовый запуск: `@cf/moonshotai/kimi-k2.6` недоступна на Workers Free. Каталог модели указывает необходимость Workers Paid либо предоплаченных AI Gateway credits. До получения платного доступа не включать флаг: запросы будут падать в резервный маршрут, а Galaxy Swarm фактически не перейдёт на Kimi.

После включения сначала проверить preview-деплой, фактический выбор модели, резервный маршрут и расходы. Не считать всех агентов переключёнными, пока не проверены остальные независимые execution paths и tool calling.
