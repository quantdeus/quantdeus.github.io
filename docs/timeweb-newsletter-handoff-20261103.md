## 1. Восстановить HTTPS WordPress (не трогая почтовые DNS)

В Timeweb проверить, что сайт привязан к `quantdeus.ru`, A/AAAA-записи идут на правильный сервер, HTTPS-сертификат выпущен на `quantdeus.ru` (и `www` при использовании). Выпустить/перевыпустить сертификат через панель Timeweb, проверить цепочку и hostname. Не выключать TLS-проверку MCP и не менять MX/SPF/DKIM/DMARC наугад. Повторить безопасные read-only вызовы WordPress MCP: `site-get-homepage`, `page-find`, `plugin-list`.

## 3. Подключить существующую форму и реальный SMTP

- Перепроверить, какие плагины реально установлены/активны **после миграции**. Выбранная архитектура: Groundhogg (подписчики, согласие, события, очереди) и SMTP Mailer (транспорт `wp_mail`).
- В **настройках WordPress** SMTP Mailer указать `smtp.timeweb.ru`, 465 + SSL/TLS, SMTP Auth, From `info@quantdeus.ru`, имя отправителя `QuantDeus`. Использовать пароль ящика только через защищённый интерфейс/настройки сервера. **Не** копировать значение GitHub secret `QD_MAIL_DATA` в исходники, issue, логи, HTML или JavaScript.
- Сначала повторить единичный WordPress SMTP тест на разрешённый адрес владельца и проверить фактическое получение. GitHub Action тест от 03.11 подтверждает только отправку из GitHub Actions, не WordPress.
- Найти имеющуюся форму на главной. Вместо создания второй формы интегрировать её с Groundhogg, либо заменить на рабочий shortcode встроенной формы Groundhogg с сохранением UX.
- Поля: email, выбор темы (эко, книги, ИИ/бизнес, медиа), **пустой по умолчанию чекбокс** добровольного согласия, ссылка на опубликованную политику обработки данных. Сообщать примерную частоту и про право отказаться.
- Состояния: `pending_confirmation` при отправке формы, подтверждение через письмо с одноразовой ссылкой, затем `confirmed`. Неподтверждённые **не получают** маркетинговые рассылки. Сведения о согласии и email хранить **только** в приватной базе WordPress/CRM (не в GitHub).
- Настроить рабочую отписку одним действием, дедупликацию, стоп-лист, лимит по умолчанию максимум 1 маркетинговое письмо за 7 дней для одного человека по всем темам. Не записывать посетителей, клиентов и пользователей форума в список автоматически.
- Отделять разрешённое подтверждение подписки от отправки автоматических маркетинговых серий. Не активировать массовые кампании до сквозного теста получателя, отмены и отдельной проверки контента.
