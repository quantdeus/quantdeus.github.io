## Границы доступа

- YouTube: публичные счётчики доступны; права публикации в GitHub Actions не подтверждены; публикации разрешать только отдельно и после успешной проверки владельца/квоты.
- VK: чтение статистики группы `andromeda_2077` доступно. Постинг, клипы и ответы этим тестом не проверялись.
- Команды не получают разрешения на массовую рассылку, накрутки, скрытую публикацию, расходы и изменение платёжных реквизитов.
- При ошибке `429` немедленно останавливаем попытки. Без циклического повтора и обходов лимита.
- Никакие значения секретов, OAuth-токены и данные пользователей не помещаются в GitHub-логи или файлы репозитория.
